## Coding Conventions
- Use detailed Javadoc-style comments for each solution, including problem description, constraints, approach, key insights, and time/space complexity
- Implement solutions in a `Solution` class with public methods matching LeetCode signatures
- Include multiple solution variants when applicable (e.g., recursive vs iterative)
- Handle edge cases explicitly
- Use clear, descriptive variable names
- Prefer standard Java libraries (e.g., `HashMap`, `ArrayList`) over custom implementations

## Project Structure
- Solutions are organized into folders by algorithmic category (e.g., `Arrays_and_hashing`, `Binary_search`)
- Each file is named as `{problem_number}_{problem_title}.java`
- Files contain complete, self-contained solutions with comments
